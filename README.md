# NeuroAPI 🧠

Сайт-магазин доступа к нейросетям: лендинг, регистрация, личный кабинет
с балансом и покупкой API-ключей (Flask + MySQL).

## Как запустить

```bash
python app.py
```

и открыть http://127.0.0.1:5000 — как и раньше, один файл `app.py`.

Перед первым запуском нужны зависимости:

```bash
pip install flask mysql-connector-python python-dotenv
# или через uv: uv sync
```

## Настройка базы (.env)

Скопируй `.env.example` в `.env` и впиши доступы к MySQL и `SECRET_KEY`.
Файл `.env` в `.gitignore` — в git не попадёт.

При старте сервер сам создаёт таблицу `api_keys` (если её нет). Таблица
`users` должна существовать: `id`, `username`, `email`, `password_hash`, `balance`.

## Демо без MySQL

Если базы под рукой нет (или хостер закрывает внешние подключения), можно
погонять весь сайт на локальной SQLite — без всякой настройки:

```bash
python demo_run.py
```

Тот же сайт, но данные лежат в файле `/tmp/neuroapi_demo.db`.

## Что умеет

- Лендинг с каталогом моделей (NeuroText, NeuroVision, NeuroVoice, NeuroEmbed)
- Регистрация и вход (пароли — хэши Werkzeug; старые SHA-256 мигрируют сами)
- Демо-пополнение баланса
- Покупка доступа: списание с баланса и выдача API-ключа `nk_...`
- Отзыв ключа
- API: `/api/login`, `/api/register`, `/api/me`, `/api/topup`, `/api/purchase`, `/api/revoke_key`

## Структура

```
app.py          — сервер: страницы, API, работа с БД
demo_run.py     — запуск в демо-режиме (SQLite вместо MySQL)
templates/      — лендинг, вход, регистрация, кабинет
static/         — стили и скрипты
```

## Безопасность

- Секреты только через переменные окружения (`.env`), в коде их нет
- Хэши паролей PBKDF2; debug-режим только при `FLASK_DEBUG=1`
- SQL-запросы параметризованные; списание баланса атомарное
